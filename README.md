# PublicIpWidget-info

Small Android home-screen widget that displays:

🇫🇷 82.xxx.xxx.xxx

It uses:

https://ipinfo.io/json

Tap the widget to refresh immediately.

The project also schedules a refresh roughly every 30 seconds when Android allows it. Android may delay background alarms because of battery/Doze restrictions.

## Android Studio

1. Extract this ZIP.
2. Open the folder `PublicIpWidget-info` in Android Studio.
3. Let Gradle Sync finish.
4. Run/build the app.
5. Install it on the phone.
6. Long-press the home screen -> Widgets -> Public IP Widget.
7. Add the widget.
